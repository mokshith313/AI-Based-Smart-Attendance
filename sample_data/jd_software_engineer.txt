Job Title: Senior Backend Software Engineer

Company: NexusTech Innovations
Location: San Francisco, CA / Remote

Job Description:
NexusTech Innovations is looking for an experienced Senior Backend Software Engineer to architect and build scalable cloud APIs and microservices.

Key Responsibilities:
- Design, develop, and maintain high-performance RESTful and GraphQL APIs using Python (FastAPI / Django) and Node.js.
- Architect database schemas and optimize query performance across PostgreSQL, Redis, and MongoDB.
- Build CI/CD pipelines and deploy containerized applications to AWS (ECS, Lambda, S3, EKS).
- Collaborate with frontend engineers to integrate web applications built with React and TypeScript.
- Mentor junior software engineers and conduct thorough code reviews.

Qualifications & Skills:
- 4+ years of professional software engineering experience.
- Expert proficiency in Python, SQL, REST APIs, and System Design.
- Strong hands-on experience with Docker, Kubernetes, AWS, and Git.
- Solid understanding of software testing (pytest) and Agile development.
- Bachelor's degree in Computer Science or equivalent field.
